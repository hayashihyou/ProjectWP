# ミニゲームの作り方

**対象：ミニゲーム担当者**（ルールを書く人）
UI の作り方・ボタン入力の送り方は、[02_情報の送信と受信.md](02_情報の送信と受信.md) を見てください。

---

## 0. 全体像：誰が何を書くか

| 担当 | 書くもの | Netcode の知識 |
|---|---|---|
| **基盤（もうある）** | 全員そろうのを待つ／カウントダウン／制限時間／ラウンドの繰り返し／値の同期／順位／結果 | — |
| **ミニゲーム担当（あなた）** | **ルールだけ**。「ボタンが押されたら値をいくつにするか」など | **不要** |
| UI 担当 | 画面の表示・演出 | 不要 |

あなたが書くのは、`MinigameBase` を**継承した1つのスクリプト**だけです。
ネットワークで送る処理（`NetworkVariable`・RPC）は、基盤が全部やります。

```
各端末のボタン ──SendAction("Stop")──▶ あなたのスクリプト(サーバーで動く)
                                         │ ServerSetValue(slot, 値) など
                                         ▼
                                    基盤が全員に同期 ──▶ 各端末の UI
```

**大事なきまり**：あなたのスクリプトのメソッドは、**サーバー（ホストの端末）でだけ**動きます。
名前が `OnServer` で始まるメソッド・`Server` で始まるメソッドは、サーバー専用です。

## 1. 作る手順

### 手順1　シーンを作る
1. `Assets/Scenes` で右クリック →「Create」→「Scene」
2. 名前を `SceneNames.cs` にある名前にする（`MG_Stopwatch` / `MG_PieThrow` / `MG_CameraCenter`）
3. シーンに置くもの
   - **カメラとライト**
   - **`PlayerSpawnPoints`**：空のオブジェクトに付けて、`Spawn Points` に **1P〜4P の初期位置**（空のオブジェクトの Transform）を4つ設定する
     （キャラクターは前のシーンから引き継がれるので、**キャラクターを置く必要はありません**）
   - 迷ったら、`Test_Player` シーンを複製して作ると、ここまでがそろっています

### 手順2　シーンを登録する
1. 「File」→「Build Profiles」→「Scene List」に、作ったシーンを追加する
2. `Assets/Script/GameFlow/SceneNames.cs` に名前がなければ足す

### 手順3　スクリプトを作る（テンプレートをコピー）
1. `Assets/Script/Minigame` の中に、ミニゲーム用のフォルダを作る（例：`Stopwatch`）
2. その中に「Create」→「Scripting」→「Empty C# Script」で、ファイルを作る（例：`StopwatchMinigame`）
3. 中身を全部消して、**`Docs/Minigame/Templates/MinigameTemplate.cs.txt` の中身をそのまま貼り付ける**
4. **6行目**の `MinigameTemplate` を、**ファイル名と同じ名前**に変える

```csharp
public class StopwatchMinigame : MinigameBase // ★2 クラス名を変える(ファイル名と同じにする)
```

### 手順4　テンプレートの ★ の場所を書き換える
テンプレートには、書き換える場所に **★番号** が付いています。

| ★ | 行 | 何を書く | 使わないとき |
|---|---|---|---|
| ★1 | 4 | ミニゲームの説明 | — |
| ★2 | 6 | クラス名（ファイル名と同じ） | — |
| ★3 | 8〜11 | **インスペクターで変えたい値**（目標の秒数・得点など）。`[Header]` `[Tooltip]` を日本語で付ける | 消す |
| ★4 | 13〜14 | サーバーだけで使う変数（タイマーなど） | 消す |
| ★5 | 22〜27 | **全員そろった直後に1回だけ**やること（`OnServerGameSetup`） | メソッドごと消す |
| ★6 | 29〜33 | **各ラウンドの開始時**にやること（`OnServerRoundStart`） | メソッドごと消す |
| ★7 | 35〜39 | **プレイ中に毎フレーム**やること（`OnServerPlayUpdate`）。時間で何か起こすとき | メソッドごと消す |
| ★8 | 41〜53 | **ボタンが押されたとき**の判定（`OnServerPlayerAction`） | メソッドごと消す |
| ★9 | 44 | 行動の名前。**入力側の `SendAction("…")` と同じ文字**にする | — |
| ★10 | 50 | その人の**今回の値**を決める行 | — |
| ★11 | 55〜66 | **ラウンドの終わり**に値を確定させる（押さなかった人に罰の値、など） | メソッドごと消す |
| ★12 | 68〜71 | 次のラウンドの前の、**このミニゲームだけのリセット** | メソッドごと消す |

**テンプレートの中身は、そのまま「ストップウォッチ」として動く例**になっています。
ほかのミニゲームでは、★8〜★11 の中身を自分のルールに書き換えてください。

### 手順5　シーンに置く
1. Hierarchy で「Create Empty」→ 名前を `Minigame` にする
2. Add Component で、次を付ける
   - **`NetworkObject`**（必須。ないと同期されません）
   - **手順3で作ったスクリプト**（例：`StopwatchMinigame`）
   - **終了条件**（必要なものだけ。「Add Component」→「Minigame」→「終了条件」）

| 終了条件 | 使う場面 |
|---|---|
| 全員が終えた | 全員が `ServerSetFinished` されたら終わる（ストップウォッチ） |
| 値が目標に届いた | 「誰か1人が10点取ったら」「全員が5回成功したら」など |
| 残り人数 | 「最後の1人になったら」（脱落のあるゲーム） |

- 終了条件は**何個付けてもよく**、**どれか1つ**を満たすとラウンドが終わります
- 制限時間は、終了条件ではなく、下の設定（`Round Time Limit`）で決めます
- `MinigameBase` を継承したスクリプトは、**1シーンに1つだけ**置いてください

### 手順6　インスペクターで設定する
手順5で付けたスクリプトの Inspector で設定します。項目にマウスを乗せると、日本語の説明が出ます。

| 見出し | 設定 | 意味 | ストップウォッチの例 | パイ投げの例 |
|---|---|---|---|---|
| 流れ | Countdown Seconds | カウントダウンの秒数（0 = 「スタート」の合図だけ） | 3 | 3 |
| ラウンド | Total Rounds | ラウンド数（1 = ラウンド制ではない） | 3 | 1 |
| | Round Time Limit | 1ラウンドの制限時間（0 = 制限なし） | 15 | 60 |
| | Round Aggregation | ラウンドの値のまとめ方（Sum 合計 / Best 一番よい / Last 最後 / RankPoints 勝ち点） | Sum | （使わない） |
| | Rank Points | RankPoints のときの、1位〜4位の点数 | — | — |
| 結果 | Win Order | HigherIsBetter 大きいほど勝ち / LowerIsBetter 小さいほど勝ち | **LowerIsBetter** | HigherIsBetter |
| | Value Kind | 値の種類（Score 得点 / Time 時間 / Count 回数） | Time | Score |
| | Value Format | 表示の形式（`0` 整数、`0.00` 小数第2位まで） | `0.00` | `0` |
| | Value Unit | 単位 | `秒` | `点` |
| リセット | Spawn Points | 初期位置（空欄ならシーンから自動で探す） | 空欄 | 空欄 |
| | Fade On Round Reset | ラウンドの間に画面を暗くして位置を戻す | オン | （使わない） |
| このミニゲームの設定 | （★3 で作ったもの） | | Target Seconds 10 | |

### 手順7　ミニゲーム選択から行けるようにする
1. `Assets/Script/Minigame/MinigameType.cs` に、ミニゲームの種類を1行足す（林さんの仕組み）
2. `03_StageSelect` シーンのミニゲーム選択ボタン（`MinigameSelectButton`）で
   - `Minigame Type`：手順1で足した種類
   - `Scene Name`：手順1のシーン名
   - `Is Available`：オン

### 手順8　MPPM で確認する
1. `01_Title` から再生 → ホストで部屋を作る → 参加者が入る → スタート → ミニゲームを選ぶ
2. **ほかの人が使っていないサーバー**を選んでください（Server 1/2/3 はチーム全員で共有です。「〇〇に参加しています」と出たら、誰かの部屋に入っています）
3. キーボードで試すときは、**Game ビューをクリックしてから**キーを押してください

確認用の見本として、`Assets/Script/Minigame/Test/` に次の2つがあります。
- `TestMinigame.cs`：ルール側の見本（1秒ごとに値を足す・`Stop` を受け取る）
- `TestMinigameInfoDisplay.cs`：画面表示の見本（`MinigameInfo` だけを使う）

## 2. 書ける場所（override するメソッド）一覧
どれも**任意**です。必要なものだけ `override` してください。すべて**サーバーでだけ**呼ばれます。

| メソッド | 呼ばれるとき | よくある使い道 |
|---|---|---|
| `OnServerGameSetup()` | 全員そろった直後に1回 | 目標の値を決めて `ServerSetInfo` で配る |
| `OnServerRoundStart(int round)` | 各ラウンドのプレイ開始時（カウントダウンの後） | タイマーを0に戻す |
| `OnServerPlayUpdate(float deltaTime)` | プレイ中、毎フレーム | 時間で起きる出来事（カメラマン登場など） |
| `OnServerPlayerAction(int slot, string actionName, MinigameValue value, double pressedServerTime)` | 誰かが `SendAction` したとき | ボタンの判定 |
| `OnServerRoundEnd(int round)` | ラウンドが終わったとき | 押さなかった人に罰の値 |
| `OnServerRoundReset(int nextRound)` | 次のラウンドの前 | このミニゲームだけのリセット |
| `CalculateRanking()` | ゲームの最後 | 「脱落した順」など、値で決まらない順位にしたいときだけ |

- `OnServerPlayerAction` には、**プレイ中・脱落していない人の行動だけ**が届きます（基盤が確かめています）
- `slot` は**枠番号**（0 = 1P、1 = 2P …）です。誰が押したかは基盤が送信元から判定するので、信用してよい値です
- `pressedServerTime` は**押した瞬間のサーバー時刻**です。プレイ開始からの秒数は `pressedServerTime - ServerRoundStartTime` で出せます

## 3. 呼べるメソッド一覧（サーバーのみ）

| メソッド | 内容 | 例 |
|---|---|---|
| `ServerSetValue(slot, 値)` | 今回のラウンドの値を**設定** | 誤差を入れる |
| `ServerAddValue(slot, 増やす量)` | 今回のラウンドの値に**足す** | パイが当たったら +1 |
| `ServerSetFinished(slot)` | この人は**このラウンドを終えた** | ストップウォッチを止めた |
| `ServerEndRound()` | **今すぐ**ラウンドを終える | 写真を撮った瞬間 |
| `ServerSetInfo("名前", 値)` | 独自の**情報**（いつでも読める状態）を全員に | 目標時間 = 10 |
| `ServerSendEvent("名前", 値, slot)` | 独自の**出来事**（その瞬間の合図）を全員に。値と slot は省略可 | 「撮影」「ストップ」 |

値（`MinigameValue`）には、`int` / `float` / `bool` / 文字列 / `Vector3` を**そのまま書けます**（`10`、`0.5f`、`true`、`"赤"`、`transform.position`）。

## 4. 読める値一覧

| 書き方 | 内容 |
|---|---|
| `PlayerCount` / `GetPlayer(i)` | 全員の情報（枠番号の順）。`.SlotIndex` `.RoundValue` `.TotalValue` `.IsFinished` など |
| `TryGetPlayerBySlot(slot, out var p)` | 枠番号から1人の情報を探す |
| `CurrentRound` / `TotalRounds` | 今のラウンド（1から）／全体のラウンド数 |
| `ServerRoundStartTime` | 今のラウンドのプレイが始まったサーバー時刻 |
| `Phase` | 今のフェーズ |

## 5. 例：3つのミニゲームではこう書く

### ストップウォッチ（テンプレートのまま）
- 設定：Total Rounds 3 / Win Order **LowerIsBetter** / Value Format `0.00` / Unit `秒`
- 終了条件：**全員が終えた**
- ★8：`"Stop"` が来たら、`|経過秒 − 目標秒|` を `ServerSetValue`、`ServerSetFinished`
- ★11：押さなかった人に罰の値

### パイ投げ（得点）
- 設定：Total Rounds 1 / Round Time Limit 60 / Win Order HigherIsBetter
- パイが当たったかの判定は、**サーバーで**行い、当たったら投げた人に点を足します
```csharp
// サーバーで「throwerSlot の人が投げたパイが当たった」と分かったところで
ServerAddValue(throwerSlot, 1);
ServerSendEvent("命中", 1, throwerSlot); // 「+1」の演出のきっかけ
```
- 投げる操作は、入力側で `MinigameInfo.SendAction("Throw")` → ★8 で `"Throw"` を受け取って、サーバーでパイを出します

### カメラの中心に写れ（不規則な流れ）
- 設定：Countdown Seconds **0**（スタートの合図だけ） / Round Time Limit **0**（制限なし）
- 流れは ★7 で自分で数えて、`ServerSendEvent` と `ServerEndRound` で進めます
```csharp
private float timer;
private bool cameramanShown;

protected override void OnServerRoundStart(int round)
{
    timer = 0f;
    cameramanShown = false;
}

protected override void OnServerPlayUpdate(float deltaTime)
{
    timer += deltaTime;

    if (!cameramanShown && timer >= 3f)
    {
        cameramanShown = true;
        ServerSendEvent("カメラマン登場");
    }

    if (timer >= 8f)
    {
        ServerSendEvent("撮影");
        // ここで一番中心に近い人に ServerAddValue(slot, 1)
        ServerEndRound();
    }
}
```

## 6. やってはいけないこと・注意

| ❌ やってはいけない | ⭕ こうする | 理由 |
|---|---|---|
| クライアント（参加者）の `Update` で点を足す | サーバーの ★7 / ★8 で `ServerAddValue` | 判定はサーバーだけ。参加者の端末で足しても全員には届かない |
| サーバーでキャラクターの `transform.position` を直接書き換える | `PlayerSlot.MoveTo(位置, 向き)` を使う | 位置は「操作している本人の端末」が動かす仕組みなので、サーバーが書き換えても戻される |
| 各端末で `Random` を使って目標を決める | サーバーで決めて `ServerSetInfo` で配る | 端末ごとに違う値になってしまう |
| `SceneManager.LoadScene` を直接呼ぶ | `NetworkSceneTransition.Instance.LoadSceneForAllAsync(シーン名)`（ホストだけ） | 全員が一緒に移動しなくなる |
| 名前の文字（`"Stop"`、`"目標時間"`）を打ち間違える | 送る側と受け取る側で、同じ文字をコピーして使う | 1文字違うと届かない（エラーも出ない） |
| `MinigameBase` を継承したスクリプトを1シーンに2つ置く | 1つだけ置く | 窓口（`MinigameInfo`）が1つのミニゲームしか扱えない |

### まだできていないこと（基盤の今後のステップ）
- **操作の可否・脱落・途中で抜けた人**（ステップ12）：`ServerEliminate` はまだありません。キャラクターの移動を止める仕組みも、今は林さんの `PlayerMinigameInput` 側です
- **演出の差し込み**（ステップ13）：イントロ・ラウンド開始・ラウンド終了・ゲーム終了の演出と、ホストのスキップ
- **結果の後の行き先**（ステップ14）：もう一度／ステージセレクトへ／タイトルへ

## 7. よくある質問

**Q. `OnServerPlayerAction` が呼ばれない**
- 入力側の `SendAction("…")` と、★9 の名前が同じか確かめてください
- プレイ中（カウントダウンの後）に押していますか？それ以外の操作は無視されます
- キーボードで試すときは、Game ビューをクリックしてから押してください

**Q. 参加者の画面で値が変わらない**
- 値を変えているのが `ServerSetValue` / `ServerAddValue` か確かめてください。自分で作った変数を変えても、ほかの人には届きません

**Q. クライアントで `Server〜` を呼んだらどうなる？**
- Console に「〇〇はサーバーでしか呼べません」と警告が出て、何も起きません
