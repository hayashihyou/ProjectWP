# ミニゲームの作り方

**対象：ミニゲーム担当者**（ルールを書く人）

## 結論：やることは3つだけ

1. **`MinigameBase` を継承したスクリプトを1つ作る**
2. **Hierarchy に空のオブジェクト（Create Empty）を作り、そのスクリプトを Add Component する**（`NetworkObject` も一緒に付ける）
3. **そのスクリプトに、ゲームの流れや判定を書く**（「ボタンが押されたら値をいくつにするか」など）

カウントダウン・制限時間・ラウンドの繰り返し・全員への同期・順位・結果は、**`MinigameBase` がもうやってくれます**。
あなたが書くのは、そのミニゲームだけのルールです。書いたメソッドは、すべて**サーバー（ホストの端末）でだけ**動きます。

### コードを書かずに、インスペクターで決められること
- **流れ**：カウントダウンの秒数、ラウンド数、1ラウンドの制限時間
- **勝ち負け**：大きい／小さいほど勝ち、ラウンドの値のまとめ方（合計・ベストなど）
- **表示**：値の種類・形式・単位（例：「0.00秒」「12点」）
- **終わり方**：終了条件を Add Component で付けるだけ（全員が終えた／値が目標に届いた／残り人数）
- **ラウンドの間**：位置を戻すときにフェードするか

→ 詳しくは [手順5](#手順5インスペクターで設定する)。**ここにあることは、コードで書かなくて大丈夫です。**

## 1. 作る手順

### 手順1　シーンを作る
1. `Assets/Scenes` で右クリック →「Create」→「Scene」
2. 名前を `SceneNames.cs` にある名前にする（`MG_Stopwatch` / `MG_PieThrow` / `MG_CameraCenter`）
3. シーンに置くもの
   - **カメラとライト**
   - **`PlayerSpawnPoints`**：空のオブジェクトに付けて、`Spawn Points` に **1P〜4P の初期位置**（空のオブジェクトの Transform）を4つ設定する
     （キャラクターは前のシーンから引き継がれるので、**キャラクターを置く必要はありません**）
   - 迷ったら、`Test_Player` シーンを複製すると、ここまでがそろっています

### 手順2　シーンを登録する
1. 「File」→「Build Profiles」→「Scene List」に、作ったシーンを追加する
2. `Assets/Script/GameFlow/SceneNames.cs` に名前がなければ足す

### 手順3　スクリプトを作る
1. `Assets/Script/Minigame` の中に、ミニゲーム用のフォルダを作る（例：`Stopwatch`）
2. その中に「Create」→「Scripting」→「Empty C# Script」でファイルを作る（例：`StopwatchMinigame`）
3. 中身を、次のように書く（**クラス名はファイル名と同じ**にする）

```csharp
using UnityEngine;

/// <summary>ストップウォッチ: 目標の秒数ぴったりで止める。誤差が小さいほど勝ち</summary>
public class StopwatchMinigame : MinigameBase
{
}
```
これだけで、カウントダウン・制限時間・ラウンドの繰り返し・順位・結果は**もう動きます**。
あとは `{ }` の中に、**「2. 書ける場所」から必要なものだけ**足していきます。

### 手順4　シーンに置く
1. Hierarchy で「Create Empty」→ 名前を `Minigame` にする
2. Add Component で、次を付ける
   - **`NetworkObject`**（必須。ないと同期されません）
   - **手順3で作ったスクリプト**
   - **終了条件**（必要なものだけ。「Add Component」→「Minigame」→「終了条件」）

| 終了条件 | 使う場面 |
|---|---|
| 全員が終えた | 全員が `ServerSetFinished` されたら終わる（ストップウォッチ） |
| 値が目標に届いた | 「誰か1人が10点取ったら」「全員が5回成功したら」など |
| 残り人数 | 「最後の1人になったら」 |

- 終了条件は何個付けてもよく、**どれか1つ**を満たすとラウンドが終わります
- 制限時間は、終了条件ではなく、下の設定（`Round Time Limit`）で決めます
- `MinigameBase` を継承したスクリプトは、**1シーンに1つだけ**置いてください

### 手順5　インスペクターで設定する
項目にマウスを乗せると、日本語の説明が出ます。

| 見出し | 設定 | 意味 | ストップウォッチ | パイ投げ |
|---|---|---|---|---|
| 流れ | Countdown Seconds | カウントダウンの秒数（0 = 「スタート」の合図だけ） | 3 | 3 |
| ラウンド | Total Rounds | ラウンド数（1 = ラウンド制ではない） | 3 | 1 |
| | Round Time Limit | 1ラウンドの制限時間（0 = 制限なし） | 15 | 60 |
| | Round Aggregation | ラウンドの値のまとめ方（Sum 合計 / Best 一番よい / Last 最後 / RankPoints 勝ち点） | Sum | — |
| | Rank Points | RankPoints のときの、1位〜4位の点数 | — | — |
| 結果 | Win Order | HigherIsBetter 大きいほど勝ち / LowerIsBetter 小さいほど勝ち | **LowerIsBetter** | HigherIsBetter |
| | Value Kind | 値の種類（Score 得点 / Time 時間 / Count 回数） | Time | Score |
| | Value Format | 表示の形式（`0` 整数、`0.00` 小数第2位まで） | `0.00` | `0` |
| | Value Unit | 単位 | `秒` | `点` |
| リセット | Spawn Points | 初期位置（空欄ならシーンから自動で探す） | 空欄 | 空欄 |
| | Fade On Round Reset | ラウンドの間に画面を暗くして位置を戻す | オン | — |

### 手順6　ミニゲーム選択から行けるようにする
1. `Assets/Script/Minigame/MinigameType.cs` に、ミニゲームの種類を1行足す
2. `03_StageSelect` シーンのミニゲーム選択ボタン（`MinigameSelectButton`）で
   - `Minigame Type`：手順6-1で足した種類
   - `Scene Name`：手順1のシーン名
   - `Is Available`：オン

[03_MPPMで4人で確認する方法.md](03_MPPMで4人で確認する方法.md) を見てください。

## 2. 書ける場所（必要なものだけ `override` する）

ミニゲームの流れの中で、**基盤が決まったタイミングで呼んでくれる**メソッドです。

```
全員そろう ─▶ OnServerGameSetup                  (1回だけ)
   ┌─ カウントダウン
   │  ─▶ OnServerRoundStart                       (ラウンドの始め)
   │  ─▶ OnServerPlayUpdate  ← プレイ中は毎フレーム
   │      OnServerPlayerAction ← 誰かがボタンを押すたび
   │  ─▶ OnServerRoundEnd                         (ラウンドの終わり)
   │  ─▶ OnServerRoundReset                       (次のラウンドの前)
   └─ ラウンドの回数だけ繰り返す
結果
```

| メソッド | こんなときに書く | 例 |
|---|---|---|
| `OnServerGameSetup()` | ゲーム全体で1回だけ決めること | 目標の秒数を決めて、全員に見せる |
| `OnServerRoundStart(int round)` | ラウンドごとに最初にやること。`round` は今のラウンド（1, 2, 3） | タイマーを 0 に戻す |
| `OnServerPlayUpdate(float deltaTime)` | 時間がたつと起きること | 3秒後にカメラマンを出す |
| `OnServerPlayerAction(...)` | **ボタンが押されたときの判定** | 押した人の誤差を計算する |
| `OnServerRoundEnd(int round)` | ラウンドの最後に、値を確定させる | 押さなかった人に罰の値を入れる |
| `OnServerRoundReset(int nextRound)` | このミニゲームだけの片付け（キャラの位置は基盤が戻す） | 出した物を消す |

### `OnServerPlayerAction` に届くもの
```csharp
protected override void OnServerPlayerAction(int slot, string actionName, MinigameValue value, double pressedServerTime)
```
| 引数 | 中身 | 例 |
|---|---|---|
| `slot` | **押した人の枠番号**（0 = 1P、1 = 2P …）。基盤が判定するので信用してよい | `1`（2Pが押した） |
| `actionName` | 入力側が `SendAction("…")` で付けた名前 | `"Stop"` |
| `value` | 入力側が一緒に送った値（送っていなければ空） | 投げる向きなど |
| `pressedServerTime` | **押した瞬間**のサーバー時刻。プレイ開始からの秒数は `pressedServerTime - ServerRoundStartTime` | 3.21秒で押した |

- 届くのは、**プレイ中**で、**脱落していない人**の行動だけです（カウントダウン中に押しても届きません）

## 3. 呼べるメソッド（サーバーのみ）

| メソッド | 何が起きるか |
|---|---|
| `ServerSetValue(slot, 値)` | その人の今回の値が「値」になり、**全員の画面に届く** |
| `ServerAddValue(slot, 増やす量)` | その人の今回の値が「増やす量」だけ増え、**全員の画面に届く** |
| `ServerSetFinished(slot)` | その人が「このラウンドを終えた」になる（終了条件「全員が終えた」に使われる） |
| `ServerEndRound()` | **今すぐ**ラウンドが終わる |
| `ServerSetInfo("名前", 値)` | 全員が**いつでも読める情報**になる（UI は `GetInfo("名前")` で読む） |
| `ServerSendEvent("名前", 値, slot)` | 全員に**その瞬間だけの合図**が届く（UI の演出のきっかけ）。値・slot は省略できる |

値には `int` / `float` / `bool` / 文字列 / `Vector3` をそのまま書けます（`10`、`0.5f`、`true`、`"赤"`）。

## 4. 読める値

| 書き方 | 返ってくるもの |
|---|---|
| `PlayerCount` | 人数 |
| `GetPlayer(i)` | i 番目の人の情報（1P, 2P … の順）。`.SlotIndex`（枠番号）`.RoundValue`（今回の値）`.TotalValue`（合計）`.IsFinished`（終えたか） |
| `TryGetPlayerBySlot(slot, out var p)` | 枠番号の人がいれば `true` と、その人の情報 `p` |
| `CurrentRound` / `TotalRounds` | 今のラウンド（1から）／全体のラウンド数 |
| `ServerRoundStartTime` | 今のラウンドのプレイが始まったサーバー時刻 |

## 5. よく使う書き方と、その結果

### 例1　ボタンが押されたら、押した人に 1 点
```csharp
protected override void OnServerPlayerAction(int slot, string actionName, MinigameValue value, double pressedServerTime)
{
    if (actionName == "Hit")
    {
        ServerAddValue(slot, 1);
    }
}
```
**結果**：2P が押すと、2P の今回の値が `0 → 1 → 2 …` と増え、**全員の画面**の2Pの点数が変わる。UI には「2P +1」の合図も届く。

### 例2　押したタイミングで値を決めて、その人を「終えた」にする（ストップウォッチ）
```csharp
[SerializeField] private float targetSeconds = 10f;

protected override void OnServerPlayerAction(int slot, string actionName, MinigameValue value, double pressedServerTime)
{
    if (actionName != "Stop") { return; }

    float elapsed = (float)(pressedServerTime - ServerRoundStartTime); // 何秒で押したか
    ServerSetValue(slot, Mathf.Abs(elapsed - targetSeconds));         // 目標とのずれ
    ServerSetFinished(slot);
}
```
**結果**：1P が 9.80秒で押すと、1P の値は `0.20` になり「終えた」になる。
終了条件「全員が終えた」を付けておけば、**全員押した瞬間にラウンドが終わる**。Win Order を LowerIsBetter にすれば、ずれが小さい人が1位になる。

### 例3　ラウンドの最後に、押さなかった人に罰の値
```csharp
protected override void OnServerRoundEnd(int round)
{
    for (int i = 0; i < PlayerCount; i++)
    {
        MinigamePlayerState player = GetPlayer(i);
        if (!player.IsFinished)
        {
            ServerSetValue(player.SlotIndex, 10f);
        }
    }
}
```
**結果**：時間切れまで押さなかった人の値が `10` になる。そのあと基盤が合計を出し直す。

### 例4　時間がたったら合図を出して、ラウンドを終える（カメラの中心）
```csharp
private float timer;

protected override void OnServerRoundStart(int round)
{
    timer = 0f;
}

protected override void OnServerPlayUpdate(float deltaTime)
{
    timer += deltaTime;
    if (timer >= 8f)
    {
        ServerSendEvent("撮影");
        ServerEndRound();
    }
}
```
**結果**：プレイ開始から8秒で、全員の UI に「撮影」の合図が届き、すぐにラウンドが終わる。
（このミニゲームは、Round Time Limit を 0（制限なし）にしておく）

### 例5　全員に見せたい情報を送る
```csharp
protected override void OnServerGameSetup()
{
    ServerSetInfo("目標時間", 10f);
}
```
**結果**：全員の UI で `MinigameInfo.GetInfo("目標時間").FloatValue` が `10` を返す。途中から画面を作っても読める。

### 例6　枠番号から、その人の今の値を調べる
```csharp
if (TryGetPlayerBySlot(slot, out MinigamePlayerState player))
{
    Debug.Log($"{slot + 1}P の今回の値は {player.RoundValue}、合計は {player.TotalValue}");
}
```
**結果**：その枠の人がいれば `true` になり、`player` にその人の情報が入る。いなければ `false`。

---

**名前の文字（`"Stop"`、`"目標時間"` など）は、送る側と受け取る側で1文字でも違うと届きません**（エラーも出ません）。コピーして使ってください。
