# 情報の送信と受信

**対象：UI 担当・入力（ボタン操作）を作る人・ミニゲーム担当**
ミニゲームそのものの作り方は、[01_ミニゲームの作り方.md](01_ミニゲームの作り方.md) を見てください。

**このガイドで使うものは、ほぼ `MinigameInfo` だけです。Netcode（`NetworkVariable`・RPC）は使いません。**

---

## 0. 情報の流れ

```
                     ┌───────────── サーバー(ホストの端末) ─────────────┐
 ③ 自分の操作        │                                                  │
  SendAction("Stop") ─▶  ミニゲームのスクリプト(OnServerPlayerAction)     │
                     │      │ ① ServerSetValue / ServerSetInfo          │
                     │      │ ② ServerSendEvent                         │
                     └──────┼───────────────────────────────────────────┘
                            ▼ 基盤が全員に届ける(ホストにも1回)
                  各端末の MinigameInfo ──▶ ④ UI が読む・イベントを受け取る
```

| 番号 | 誰が | 何をする | 使うもの |
|---|---|---|---|
| ① | ミニゲーム担当 | **状態**（いつ読んでも最新）を変える | `ServerSetValue` `ServerAddValue` `ServerSetFinished` `ServerSetInfo` |
| ② | ミニゲーム担当 | **出来事**（その瞬間の合図）を送る | `ServerSendEvent` |
| ③ | 入力を作る人 | **自分の操作**をサーバーに送る | `MinigameInfo.SendAction` |
| ④ | UI 担当 | 状態を**読む**・出来事を**受け取る** | `MinigameInfo` のプロパティとイベント |

### 「状態」と「出来事」の使い分け
| | 状態 | 出来事 |
|---|---|---|
| 意味 | いつ読んでも最新の値 | 「今起きた」という合図 |
| 例 | 残り時間、全員のスコア、目標時間 | カウントダウン、「+3点」、「ストップ！」、結果 |
| UI での受け取り方 | `Update` で**毎フレーム読む** | **イベントを登録**して待つ |
| 後から画面を作った場合 | 最新の値がすぐ読める | **過去の分は来ない** |

## 早見表：やりたいこと → 書くコード

| やりたいこと | 書くコード | 書く場所 |
|---|---|---|
| 残り時間を表示 | `MinigameInfo.RemainingTime` | UI の `Update` |
| 自分のスコアを表示 | `MinigameInfo.TryGetLocalPlayer(out var me)` → `me.TotalValue` | UI の `Update` |
| 全員のスコアを表示 | `MinigameInfo.PlayerCount` と `MinigameInfo.GetPlayer(i)` | UI の `Update` |
| 値を「12点」のように表示 | `MinigameInfo.FormatValue(値)` | UI |
| 「3, 2, 1, スタート！」 | `MinigameInfo.OnCountdown` | UI の `OnEnable` で登録 |
| 「+3点」のアニメーション | `MinigameInfo.OnPlayerValueChanged` | UI の `OnEnable` で登録 |
| 目標時間などを表示 | `MinigameInfo.GetInfo("目標時間")` | UI の `Update` |
| 「撮影」でフラッシュ | `MinigameInfo.OnCustomEvent` | UI の `OnEnable` で登録 |
| 結果画面 | `MinigameInfo.OnGameFinished` / `MinigameInfo.LastResult` | UI |
| ボタンでサーバーに送る | `MinigameInfo.SendAction("Stop")` | 入力のスクリプト |
| 今操作してよいか | `MinigameInfo.CanControl` | 入力・UI |
| 目標時間を全員に見せる | `ServerSetInfo("目標時間", 10f)` | ミニゲームのスクリプト |
| 「撮影」を全員に知らせる | `ServerSendEvent("撮影")` | ミニゲームのスクリプト |

## A. ミニゲーム担当：サーバーから全員に送る（①②）

ミニゲームのスクリプト（`MinigameBase` を継承したもの）の中で呼びます。**サーバーでだけ**使えます。

### 値（プレイヤーごとのスコアなど）
```csharp
ServerSetValue(slot, 0.35f);  // 今回の値を設定
ServerAddValue(slot, 1);      // 今回の値に足す
ServerSetFinished(slot);      // この人はこのラウンドを終えた
```
→ UI では `GetPlayer(i).RoundValue` / `.TotalValue` / `.IsFinished` で読めます。
→ 同時に、イベント `OnPlayerValueChanged`（値が変わった）・`OnPlayerFinished`（終えた）が鳴ります。

### 独自の情報（状態）
```csharp
ServerSetInfo("目標時間", 10f);   // 同じ名前なら上書き
ServerSetInfo("お題", "赤");      // 文字列も送れる(日本語で約20文字まで)
```
→ UI では `MinigameInfo.GetInfo("目標時間").FloatValue` で読めます。

### 独自の出来事
```csharp
ServerSendEvent("撮影");                    // 名前だけ
ServerSendEvent("ストップ", 3.21f, slot);   // 値と「誰の」付き
```
→ UI では `MinigameInfo.OnCustomEvent` で受け取れます。

### 基盤が自動で送るもの（担当者は何も書かなくてよい）
フェーズ・今のラウンド・残り時間・カウントダウン・ラウンド開始／終了・順位と結果

### 送れる値の種類
`int` / `float` / `bool` / 文字列（日本語で約20文字まで） / `Vector3` を、**そのまま書けます**。
受け取る側では、`.IntValue` `.FloatValue` `.BoolValue` `.TextValue` `.Vector3Value` で取り出します（`.ToString()` で文字にもできます）。

   （**`NetworkObject` は不要**です。普通の `MonoBehaviour` です）

### 読める値（プロパティ）一覧
| 書き方 | 内容 |
|---|---|
| `MinigameInfo.IsActive` | ミニゲームが動いているか（false のときは、ほかの値は初期値） |
| `MinigameInfo.Phase` | 今のフェーズ（`Countdown` / `Playing` / `Result` など） |
| `MinigameInfo.CurrentRound` / `TotalRounds` | 今のラウンド（1から）／全体のラウンド数 |
| `MinigameInfo.RemainingTime` | 残り時間（秒）。制限なし・プレイ中でないときは -1 |
| `MinigameInfo.PlayerCount` / `GetPlayer(i)` | 全員の情報（1P, 2P … の順） |
| `MinigameInfo.TryGetPlayerBySlot(slot, out var p)` | 枠番号から1人の情報 |
| `MinigameInfo.TryGetLocalPlayer(out var me)` / `LocalPlayer` / `HasLocalPlayer` | **自分（この端末）**のプレイヤー |
| `MinigameInfo.CanControl` | 今操作してよいか（プレイ中で、脱落していない） |
| `MinigameInfo.ValueKind` | 値の種類（得点 / 時間 / 回数） |
| `MinigameInfo.FormatValue(値)` | 「12点」「0.35秒」のように整形した文字 |
| `MinigameInfo.GetInfo("名前")` / `TryGetInfo` | 独自の情報 |
| `MinigameInfo.LastResult` | 最後の結果（順位の良い順）。**シーンをまたいでも残る** |

プレイヤー1人分の情報（`MinigamePlayerState`）の中身：
`SlotIndex`（0 = 1P）、`RoundValue`（今回の値）、`TotalValue`（合計）、`IsFinished`（このラウンドを終えた）、`IsEliminated`（脱落）、`IsConnected`（接続中）

### 受け取れる出来事（イベント）一覧
| イベント | 引数 | 使い道の例 |
|---|---|---|
| `OnPhaseChanged` | 新しいフェーズ | 画面の切り替え |
| `OnCountdown` | 残り秒（3, 2, 1, 0 = スタート） | 「3, 2, 1, スタート！」 |
| `OnRoundStarted` / `OnRoundEnded` | ラウンド番号 | 「ラウンド2」 |
| `OnPlayerValueChanged` | 枠番号, 変化量, 新しい値 | 「+3点」 |
| `OnPlayerFinished` | 枠番号 | 「ストップ！」 |
| `OnCustomEvent` | 名前, 値, 枠番号（誰のものでもなければ -1） | 「撮影」でフラッシュ |
| `OnGameFinished` | 結果（順位の良い順） | 結果画面 |

### UI 担当の注意
- イベントは **`OnEnable` で `+=`、`OnDisable` で `-=`** してください（テンプレートの形のまま）
- **出来事は、状態より先に届くことがあります**（通信の仕組み上）。例：`OnCountdown` が来た瞬間に、`Phase` がまだ `Countdown` になっていないことがあります。**イベントの中では、引数の値を使ってください**
- フェーズは、一瞬で過ぎると**飛ばされることがあります**。「ラウンドが終わった」を確実に知りたいときは、`OnPhaseChanged` ではなく `OnRoundEnded` を使ってください
- `MinigameInfo.Players` は、読むたびにリストを作ります。毎フレーム読むなら `PlayerCount` と `GetPlayer(i)` を使ってください
- どのイベントも、**ホストを含む各端末で1回ずつ**鳴ります

## C. プレイヤー個人：自分の操作をサーバーに送る（③）

### 手順1　スクリプトを作る（テンプレートをコピー）
1. 「Create」→「Scripting」→「Empty C# Script」でファイルを作る（例：`StopwatchInput`）
2. 中身を全部消して、**`Docs/Minigame/Templates/MinigameInputTemplate.cs.txt` の中身を貼り付ける**
3. **8行目**の `MinigameInputTemplate` を、ファイル名と同じ名前に変える

### 手順2　★ の場所を変える
| ★ | 行 | 内容 | 変えるところ |
|---|---|---|---|
| ★3 | 11 | 送る**行動の名前**（初期値 `"Stop"`） | ミニゲームのスクリプトの ★9（`OnServerPlayerAction` で見る名前）と**同じ文字**にする。Inspector でも変えられる |
| ★4 | 14 | 使うボタン（`InputActionReference`） | Inspector で、`Assets/Input` の Input Actions から使うボタンをドラッグする |
| ★5 | 40 | 送る処理 | 値も送るなら `MinigameInfo.SendAction(actionName, 値)` |

### 手順3　シーンに置く
空のオブジェクトにスクリプトを付けて、Inspector で `Action Name` と `Button` を設定します。
**`NetworkObject` は不要**です。各端末で、その端末の人の操作だけが送られます。

### いろいろな送り方
```csharp
// ① 一番かんたん(どのスクリプトからでも、この1行で送れる)
MinigameInfo.SendAction("Stop");

// ② 値も一緒に送る(int / float / bool / 文字列 / Vector3)
MinigameInfo.SendAction("Throw", transform.forward);

// ③ 画面のボタン(タッチ用)から送る
//    UI の Button の OnClick に、テンプレートのスクリプトの Send() を登録する

// ④ 林さんの PlayerMinigameInput(Aボタンのイベント)から送る
playerMinigameInput.OnConfirmPressed += () => MinigameInfo.SendAction("Stop");
```

### サーバーではこう届く（ミニゲーム担当側）
```csharp
protected override void OnServerPlayerAction(int slot, string actionName, MinigameValue value, double pressedServerTime)
{
    if (actionName == "Stop") { /* 止めた人(slot)の処理 */ }
    if (actionName == "Throw") { Vector3 direction = value.Vector3Value; /* 投げる処理 */ }
}
```
詳しくは [01_ミニゲームの作り方.md](01_ミニゲームの作り方.md) の ★8 を見てください。

### 基盤が代わりに守っていること（自分で書かなくてよい）
| 守っていること | 理由 |
|---|---|
| **誰が押したかは、送信元からサーバーが判定する**（「2Pです」と送らない） | なりすましができない |
| **プレイ中以外・脱落した人・抜けた人の操作は無視する** | カウントダウン中に押しても反応しない |
| **押した瞬間のサーバー時刻を自動で付ける** | 通信の遅れの分だけ不公平になるのを防ぐ（ストップウォッチなど） |
| 押した時刻を「プレイ開始〜今」の範囲に収める | おかしな時刻でズルできない |

送る前に `MinigameInfo.CanControl` で確かめると、むだな通信を減らせます（テンプレートはそうしています）。

## D. 確認のしかた
- 見本：`Assets/Script/Minigame/Test/TestMinigameInfoDisplay.cs`（`MinigameInfo` だけで表示し、**スペースキーで `"Stop"` を送る**）
- MPPM で確認するときは、**ほかの人が使っていないサーバー**を選び、**Game ビューをクリックしてから**キーを押してください
- 送ったのに反応しないときは、次の順で確かめてください
  1. **行動・情報・出来事の名前**が、送る側と受け取る側で同じか（1文字でも違うと届きません。エラーも出ません）
  2. **プレイ中**に押しているか（`MinigameInfo.CanControl` が true か）
  3. イベントを **`+=` で登録**しているか、そのオブジェクトが**有効**か
