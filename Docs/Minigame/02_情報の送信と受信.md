# 情報の送信と受信

**対象：UI 担当・ボタン入力を作る人**
（ミニゲーム担当が、サーバーから値や合図を送る方法は [01_ミニゲームの作り方.md](01_ミニゲームの作り方.md) にあります）

## 結論：使うのは `MinigameInfo` だけ

- **受け取る（UI）**：`MinigameInfo` を読むだけ
  - **今の値**（残り時間・スコアなど）→ `Update` で毎フレーム**読む**
  - **出来事**（カウントダウン・「+3点」など）→ イベントを `OnEnable` で**登録**して待つ
- **送る（プレイヤーの操作）**：ボタンが押されたら `MinigameInfo.SendAction("Stop");` の**1行だけ**
- どちらも**ふつうの `MonoBehaviour`** で書けます。**`NetworkObject` も Netcode も不要**です。シーンのどこに置いてもかまいません
- **名前の文字（`"Stop"`、`"目標時間"` など）は、ミニゲーム担当と同じにする**こと。1文字違うと届きません（エラーも出ません）

| 知りたいこと | 見る場所 |

| UI で値を表示する・出来事で演出する | [1. 受け取る](#1-受け取るui) |
| ボタンの操作をサーバーに送る | [2. 送る](#2-送るプレイヤーの操作) |

## 1. 受け取る（UI）

### 手順
1. 「Create」→「Scripting」→「Empty C# Script」で、UI 用のスクリプトを作る（例：`StopwatchHud`）
2. 中身を、次のように書く（クラス名はファイル名と同じにする）
```csharp
using UnityEngine;

/// <summary>ストップウォッチの画面表示</summary>
public class StopwatchHud : MonoBehaviour
{
    // 今の値は、Update で毎フレーム読む
    private void Update()
    {
        if (!MinigameInfo.IsActive) { return; } // ミニゲームが動いていないときは何もしない
    }

    // 出来事は、OnEnable で登録して、OnDisable で外す
    private void OnEnable() { }
    private void OnDisable() { }
}
```
3. Canvas の中などに空のオブジェクトを作って、このスクリプトを Add Component する
4. あとは「**読める値**」「**受け取れる出来事**」から必要なものを足していく（書き方は [3.](#3-よく使う書き方とその結果)）

### 読める値（`Update` で読む）
| 書き方 | 返ってくるもの |
|---|---|
| `MinigameInfo.RemainingTime` | 残り時間（秒）。制限なし・プレイ中でないときは `-1` |
| `MinigameInfo.CurrentRound` / `TotalRounds` | 今のラウンド（1から）／全体のラウンド数 |
| `MinigameInfo.Phase` | 今の段階（`Countdown` / `Playing` / `Result` など） |
| `MinigameInfo.TryGetLocalPlayer(out var me)` | **自分**がいれば `true` と、自分の情報 `me` |
| `MinigameInfo.PlayerCount` / `GetPlayer(i)` | 人数／i 番目の人の情報（1P, 2P … の順） |
| `MinigameInfo.FormatValue(値)` | 「12点」「0.35秒」のように整えた文字 |
| `MinigameInfo.GetInfo("名前")` | ミニゲーム担当が `ServerSetInfo` で送った情報 |
| `MinigameInfo.CanControl` | 今操作してよいなら `true`（プレイ中で、脱落していない） |
| `MinigameInfo.LastResult` | 最後の結果（順位の良い順）。シーンをまたいでも残る |

1人分の情報（`me` や `GetPlayer(i)`）の中身：`.SlotIndex`（0 = 1P）、`.RoundValue`（今回の値）、`.TotalValue`（合計）、`.IsFinished`（このラウンドを終えたか）

### 受け取れる出来事（`OnEnable` で登録する）
| イベント | いつ届く | 一緒に届くもの |
|---|---|---|
| `OnCountdown` | カウントダウンの1秒ごと | 残り秒（3, 2, 1, 0 = スタート） |
| `OnRoundStarted` / `OnRoundEnded` | ラウンドの開始／終了 | ラウンド番号 |
| `OnPlayerValueChanged` | 誰かの値が変わったとき | 枠番号, 変化量, 新しい値 |
| `OnPlayerFinished` | 誰かが「このラウンドを終えた」になったとき | 枠番号 |
| `OnCustomEvent` | ミニゲーム担当が `ServerSendEvent` したとき | 名前, 値, 枠番号（誰のものでもなければ -1） |
| `OnGameFinished` | ゲームが終わって結果が出たとき | 結果（順位の良い順） |
| `OnPhaseChanged` | 段階が変わったとき | 新しい段階 |

どのイベントも、**ホストを含む全員の端末で1回ずつ**届きます。

## 2. 送る（プレイヤーの操作）

### 手順
ボタンが押されたところに、**この1行を書くだけ**です。
```csharp
MinigameInfo.SendAction("Stop");
```
- `"Stop"` の部分は、ミニゲーム担当の `OnServerPlayerAction` で見ている名前と**同じ文字**にします
- **誰が押したか**・**押した瞬間の時刻**は、基盤が自動で付けます。自分で送る必要はありません
- **プレイ中以外**（カウントダウン中など）や、**脱落した人**の操作は、サーバーで自動的に無視されます

### 値も一緒に送るとき
```csharp
MinigameInfo.SendAction("Throw", transform.forward); // int / float / bool / 文字列 / Vector3 を送れる
```

## 3. よく使う書き方と、その結果

### 例1　残り時間を表示する
```csharp
[SerializeField] private TMPro.TMP_Text timeText;

private void Update()
{
    if (!MinigameInfo.IsActive) { return; }

    float remaining = MinigameInfo.RemainingTime;
    timeText.text = remaining >= 0 ? remaining.ToString("0") : "";
}
```
**結果**：プレイ中は `15 → 14 → 13 …` と減っていく。**全員の画面でそろう**。制限なしやプレイ中でないときは何も出ない。

### 例2　自分の点数を表示する
```csharp
if (MinigameInfo.TryGetLocalPlayer(out MinigamePlayerState me))
{
    scoreText.text = MinigameInfo.FormatValue(me.TotalValue);
}
```
**結果**：ホストの画面には1Pの、2Pの画面には2Pの点数が、「12点」のように出る（形式と単位はミニゲームの設定どおり）。

### 例3　全員の点数を並べる
```csharp
for (int i = 0; i < MinigameInfo.PlayerCount; i++)
{
    MinigamePlayerState p = MinigameInfo.GetPlayer(i);
    Debug.Log($"{p.SlotIndex + 1}P : {MinigameInfo.FormatValue(p.TotalValue)}");
}
```
**結果**：`1P : 12点`、`2P : 8点` … と、**1P から順に**全員分が取れる。

### 例4　「3, 2, 1, スタート！」を出す
```csharp
private void OnEnable()  { MinigameInfo.OnCountdown += ShowCountdown; }
private void OnDisable() { MinigameInfo.OnCountdown -= ShowCountdown; }

private void ShowCountdown(int secondsLeft)
{
    countdownText.text = secondsLeft > 0 ? secondsLeft.ToString() : "スタート！";
}
```
**結果**：1秒ごとに `3` → `2` → `1` → `スタート！` と呼ばれる。全員の画面で同時に変わる。

### 例5　「+1点」の演出を出す
```csharp
private void OnEnable()  { MinigameInfo.OnPlayerValueChanged += ShowGain; }
private void OnDisable() { MinigameInfo.OnPlayerValueChanged -= ShowGain; }

private void ShowGain(int slot, float delta, float newValue)
{
    messageText.text = $"{slot + 1}P +{delta}";
}
```
**結果**：2P の点が1増えると、`slot = 1`、`delta = 1`、`newValue = 増えた後の点` で呼ばれる。

### 例6　ミニゲーム担当が送った情報を表示する
```csharp
float target = MinigameInfo.GetInfo("目標時間").FloatValue;
infoText.text = $"{target:0.00}秒で止めろ！";
```
**結果**：ミニゲーム担当が `ServerSetInfo("目標時間", 10f)` していれば `10.00秒で止めろ！` と出る。まだ送られていなければ `0`。

### 例7　ミニゲーム担当が送った合図で演出する
```csharp
private void OnEnable()  { MinigameInfo.OnCustomEvent += HandleEvent; }
private void OnDisable() { MinigameInfo.OnCustomEvent -= HandleEvent; }

private void HandleEvent(string eventName, MinigameValue value, int slot)
{
    if (eventName == "撮影")
    {
        // フラッシュを出す
    }
}
```
**結果**：ミニゲーム担当が `ServerSendEvent("撮影")` した瞬間に、全員の画面で呼ばれる。

### 例8　結果を表示する
```csharp
private void OnEnable()  { MinigameInfo.OnGameFinished += ShowResult; }
private void OnDisable() { MinigameInfo.OnGameFinished -= ShowResult; }

private void ShowResult(System.Collections.Generic.IReadOnlyList<MinigameRankEntry> result)
{
    foreach (MinigameRankEntry entry in result)
    {
        Debug.Log($"{entry.Rank}位 {entry.SlotIndex + 1}P {MinigameInfo.FormatValue(entry.Value)}");
    }
}
```
**結果**：`1位 2P 0.12秒`、`2位 1P 0.35秒` … と、**順位の良い順**に届く。同点は同じ順位。

### 例9　ボタン（Input System）で操作を送る
```csharp
using UnityEngine;
using UnityEngine.InputSystem;

public class StopwatchInput : MonoBehaviour
{
    [SerializeField] private InputActionReference stopButton; // Assets/Input の Input Actions からドラッグ

    private void OnEnable()
    {
        stopButton.action.performed += OnStop;
        stopButton.action.Enable();
    }

    private void OnDisable()
    {
        stopButton.action.performed -= OnStop;
    }

    private void OnStop(InputAction.CallbackContext context)
    {
        if (MinigameInfo.CanControl)
        {
            MinigameInfo.SendAction("Stop");
        }
    }
}
```
**結果**：プレイ中にボタンを押すと、サーバーのミニゲーム担当の `OnServerPlayerAction` が、**押した人の枠番号**と**押した瞬間の時刻**付きで呼ばれる。カウントダウン中に押しても何も起きない。

### 例10　画面のボタン（タッチ）で操作を送る
```csharp
public void OnClickStop() // UI の Button の OnClick に登録する
{
    MinigameInfo.SendAction("Stop");
}
```
**結果**：例9と同じ。

---

- イベントは **`OnEnable` で `+=`、`OnDisable` で `-=`** を必ずセットで書いてください
- **出来事は、今の値より先に届くことがあります**。イベントの中では、**一緒に届いた値（引数）**を使ってください
- 見本：`Assets/Script/Minigame/Test/TestMinigameInfoDisplay.cs`（`MinigameInfo` だけで表示し、スペースキーで `"Stop"` を送る）
