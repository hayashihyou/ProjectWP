# MPPM で4人で確認する方法

**MPPM（Multiplayer Play Mode）** を使うと、**1台のPCで、ホスト＋参加者3人の4人分**を同時に動かして確認できます。
このプロジェクトには、4人用の設定（`Assets/Settings/PlayMode/NewPlayModeScenario`）がもう入っています。

| ウィンドウ | 役 |
|---|---|
| いつもの Unity エディタ（Main Editor） | 1人目（ふつうはホスト） |
| Player 2 / Player 3 / Player 4 | 2〜4人目（別ウィンドウで開く） |

---

## 1. 始める前に
1. **`01_Title` シーンを開いておく**（再生はタイトル画面から始めます）
2. Unity 上部の**再生ボタンの近くにあるプルダウン（Play Mode Scenario）**で、**`NewPlayModeScenario`** を選ぶ
   - 「Default」のままだと、いつもどおり1人で再生されます
   - 見当たらないときは、そのプルダウンの「Configure Play Mode Scenarios」から、`NewPlayModeScenario` を選んでください

## 2. 動かす
1. **再生ボタンを押す** → Player 2〜4 のウィンドウが開く（**初回は数十秒かかります**）
2. **Main Editor** のタイトル画面で、ボタンかクリックを1回 → サーバー一覧が出る → **誰もいないサーバー**を選ぶ
   - Console に **「Server 〇 を起動しています…」** → あなたが**ホスト**です
3. **Player 2〜4** のウィンドウで、それぞれ**同じサーバー**を選ぶ → 部屋に入る
4. Main Editor（ホスト）で、待機画面の **「スタート」** → ミニゲーム選択で、確かめたいミニゲームを選ぶ
5. 確認が終わったら、**Main Editor の停止ボタン**を押す（4人分まとめて止まります）

## 3. 操作と確認のコツ
- **キーボードで操作するときは、そのウィンドウの Game 画面を一度クリックしてから**押してください。選ばれていないウィンドウには、キー入力が入りません
- Player 2〜4 の Console は、そのウィンドウで「Window」→「General」→「Console」（`Ctrl + Shift + C`）で開けます
- 「ホストと参加者で同じ表示になっているか」は、**Main Editor と Player 2 を左右に並べて**見ると分かりやすいです
- 2人で十分なときは、Player 3・4 のウィンドウは何もしなくて大丈夫です（部屋に入らなければ、いないのと同じです）

---

## 4. ⚠️ サーバーはチーム全員で共有です
サーバー一覧（Server 1 / 2 / 3）は、**同じプロジェクトを使っているチーム全員**に同じものが見えています。
誰かが同じ時間に Server 1 でホストをしていると、あなたのウィンドウが**その人の部屋に入ってしまいます**。

- Console に **「Server 〇 に参加しています…」** と出たのに、自分で部屋を作った覚えがない → **誰かの部屋に入っています**。すぐ止めて、別のサーバーを選び直してください
- 「勝手にキャラが動く」「勝手にミニゲームが始まる」ときも、たいていこれです
- チームで「〇〇さんは Server 3 を使う」のように決めておくと安全です

## 5. 出ても気にしなくてよいエラー
次のエラーは、MPPM や Netcode の内部のものです。動きには影響しません。

| エラー | いつ出るか |
|---|---|
| `You may not pass in objects that are already persistent` | Player 2〜4 のウィンドウを開いたとき |
| `IOException: Sharing violation on path ...\Library\VP\SystemData.json` | 再生を始めた・止めたとき |
| `[Worker] AssertionException` など MPPM の起動時のエラー | エディタを起動したとき |
| `NullReferenceException`（`NetworkManager.OnApplicationQuit` などの中） | 再生を止めたとき |
| `[Wire - ws#] FATAL ... frame could not be read` | ホストとの接続が切れたとき |

**自分のスクリプトの名前が入った赤いエラー**は、気にした方がよいエラーです。

## 6. うまくいかないとき
| 症状 | 確かめること |
|---|---|
| Player 2〜4 のウィンドウが開かない | プルダウンで `NewPlayModeScenario` を選んでいるか |
| 部屋に入れない | 満員ではないか（最大4人）。ホストと同じサーバーを選んでいるか |
| キーを押しても反応しない | その Game 画面をクリックしたか。プレイ中（カウントダウンの後）か |
| 参加者の画面だけ表示がおかしい | その参加者のウィンドウの Console に赤いエラーがないか |
