# BGM・SE の追加と確認

## 1. 音を追加する
1. 音声ファイルを入れる
   - BGM → `Assets/Audio/BGM`
   - SE → `Assets/Audio/SE`
2. 入れたファイルを**右クリック →「SoundLibrary に登録」**
   - 何個かまとめて選んでもOK
   - 登録が終わると `SoundLibrary.asset` が選ばれた状態になります
3. Inspector の **一番下に増えた行**に、日本語名を2つ入れる

   | 項目 | 入れるもの | 例 |
   |---|---|---|
   | Scene Label | 使用場面 | `ストップウォッチ` |
   | Usage Label | 使用用途 | `時間を止める` |

> **Entries の「＋」で追加しないでください。** 1つ上の行の中身がコピーされて、ID の重複や設定ミスの原因になります。

### 自動で入る設定
| | ID | ループ | フェードイン / アウト |
|---|---|---|---|
| BGM フォルダのファイル | ファイル名 | ON | 0.5秒 |
| それ以外 | ファイル名 | OFF | なし |

変えたいときは、その行の項目を直接書き換えてください。

## 2. コードから鳴らす
ID（ファイル名）で鳴らします。

| 書くこと | 結果 |
|---|---|
| `SoundManager.Instance.PlaySe("SE_Jump");` | SE が1回鳴る |
| `SoundManager.Instance.PlayBgm("BGM_Title");` | BGM が流れる（前の曲からは自動で切り替わる） |
| `SoundManager.Instance.StopBgm();` | BGM が止まる |
| `var h = SoundManager.Instance.PlaySe("SE_Loop");` → `h.Stop();` | ループ SE をあとで止める |

- シーンごとの BGM は、`SceneBgm.cs` の表に1行足すと、そのシーンに入ったときに自動で流れます
- 全員に鳴らしたい音は、同期したイベント（ClientRpc など）を受け取った側で `PlaySe` を呼んでください（音そのものは同期されません）

## 3. 聞いて確かめる・音量を合わせる
1. `Assets/Scenes/SoundCheck.unity` を開いて再生
2. 右の一覧から音を選んで **PLAY**
3. **VOLUME** のスライダーで音量を合わせる → **そのまま SoundLibrary に保存されます**（再生を止めても残ります）

- BGM と SE は1つずつ同時に鳴らせるので、**BGM を流しながら SE を鳴らして**バランスを見られます
- 同じ種類の別の音を鳴らすと、今の音が消えてから次の音が始まります
- PREVIEW（フェード・ループ）のスイッチは試し聞き用です。ゲームには影響しません

## 4. 音量の設定画面（プレイヤー用）
マスター・BGM・SE の音量を変える画面です。値は自動で保存されます。

| 開き方 | 閉じ方 |
|---|---|
| 歯車アイコンのボタンを押す | 「閉じる」/ 画面の暗いところ / Esc / パッドの B |

- **歯車の画像（`Assets/UI/StageSelect/SettingsIcon.png`）を使ったボタンなら、どのシーンでも自動で開くようになります。** 何も付けなくてOKです
- 歯車以外の見た目のボタンから開きたいときは、そのボタンに **`SoundSettingsOpener`** を付けてください
- すぐ試したいときは `SoundCheck.unity` を再生して、右上の歯車を押してください
見た目は `Assets/Resources/SoundSettingsMenu.prefab` で変えられます。

## 5. 音が鳴らないとき
| 症状 | 確かめること |
|---|---|
| Console に「SoundLibrary に登録されていません」 | ID のつづり（大文字・小文字も区別されます） |
| Console に「Clip が設定されていません」 | その行の Clip に音声ファイルが入っているか |
| エラーは無いのに聞こえない | その行の Volume が 0 になっていないか / 設定画面の音量が 0 になっていないか |
| 連打しても1回しか鳴らない | その行の Min Interval（連打を無視する秒数）が大きすぎないか |
